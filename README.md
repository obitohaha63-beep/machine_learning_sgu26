## 📚 Tổng quan nội dung theo tuần

| Tuần | Chủ đề chính | Nội dung & Bài tập nổi bật |
| :--- | :--- | :--- |
| **Tuần 01** | **Tổng quan Học máy & Làm quen PyTorch** | Giới thiệu tổng quan về Machine Learning, cài đặt môi trường PyTorch, kiến thức nền tảng và thực hành `lab01.ipynb`. |
| **Tuần 02** | **Bài toán thực tế: Titanic & House Prices** | Thực hành phân loại & hồi quy nâng cao trên bộ dữ liệu *Titanic* và *House Prices*, phân tích kết quả và tạo file submission. |
| **Tuần 03** | **Hiểu về dữ liệu (Data Understanding)** | Khám phá dữ liệu, phân tích đa biến (`Phan_tich_da_bien.ipynb`) và bài tập `BT01_DataUnderstanding`. |
| **Tuần 04** | **Chọn lọc đặc trưng (Feature Selection)** | Thực hành xử lý và chọn đặc trưng qua script `chondactrung.py` và xuất kết quả `submission.csv`. |
| **Tuần 05** | **Đánh giá mô hình & Lý thuyết học** | Lý thuyết học (Learning Theory), tiền xử lý dữ liệu tín dụng (`prep_credit.py`), trực quan hóa Decision Tree (`decision_tree_depth2.png`, `titanic_tree.png`) và `BT02_ModelTrainingEvaluation`. |
| **Tuần 06** | **Hồi quy (Regression)** | Lý thuyết và bài tập hồi quy (`BT03_Regression`), thực hành trên dữ liệu `music_genre_classification_v1.csv`. |
| **Tuần 07** | **Cây quyết định, Bayes, kNN & Rule-based** | Học dựa trên cây quyết định (`BT04a`), phân lớp Bayes (`BT04b`), học dựa trên độ tương đồng / kNN (`BT04c`) và học dựa trên luật (`BT04d`). |
| **Tuần 08** | **Lý thuyết Bayes & MLE** | Phân phối chuẩn Bayes & Ước lượng hợp lý cực đại (`BT05_Bayesian_Normal_Density_MLE`). |
| **Tuần 09** | **Học không giám sát (Unsupervised Learning)** | Phân cụm (Clustering), giảm chiều dữ liệu (PCA) (`BT06_Clustering and PCA`) và ôn tập Mock MLP. |
| **Tuần 10** | **Bài tập tổng hợp (M01 & M02)** | Giải các bài tập thực hành và ôn tập chuyên đề `M01`, `M02`. |
| **Tuần 11** | **Mạng nơ-ron nhân tạo (ANN)** | Lý thuyết và bài tập thực hành về Artificial Neural Networks (`BT07_ANN`). |
| **Tuần 12** | **Cập nhật sau** | *(Thư mục hiện đang trống)* |
